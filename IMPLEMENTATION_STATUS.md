### Coverage limits and follow-ups, not automatic release blockers

The specification explicitly permits manual SMART imports and manual recovery evidence when APIs cannot supply trustworthy data. Additional passive exporters, automatic recovery adapters and hardware compatibility discovery are follow-ups unless installed-source discovery identifies a required gap. Per-model temperature guidance is an alternative to the implemented explicit local policy. Generated API types, query caching and demo mode are engineering/product follow-ups, not requirements stated in the supplied specification. Dataset forecasts and broader homelab adapters must not be conflated with the implemented pool forecast or used to delay the required storage/recovery acceptance work. Mixed observations inside one original identity record cannot currently be repartitioned; reversible grouping/splitting of original records is implemented and must retain provenance.
